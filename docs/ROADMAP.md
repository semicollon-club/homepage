# 개발 로드맵 & 진행 추적

세미콜론 공개 홈페이지의 개발 단계를 정의하고 진행 상황을 추적하는 문서입니다.
작업을 완료하면 체크박스를 갱신하고, 필요 시 항목을 추가하세요.

## 진행 상태 표기

- `[ ]` 예정 · `[~]` 진행 중 · `[x]` 완료

## 사이트의 목표

모든 페이지는 아래 셋 중 하나를 위해 존재합니다. 어디에도 속하지 않는 페이지는 만들지 않습니다.

1. **신입 모집** — 방문자 대다수는 가입을 고민하는 학생
2. **활동 증명** — 학교·외부에 "실제로 활동하는 동아리"임을 보여주는 아카이브
3. **정보 제공** — 공지, 일정, 연락처

## 사이트맵 (목표 구조)

```
/                  랜딩 (요약 + 각 페이지 진입 허브)
├─ /about          동아리 소개
├─ /organization   조직도 ✅
├─ /activities     활동 소개 (스터디·프로젝트·행사)
├─ /recruit        가입 안내 (절차·FAQ·지원 버튼)
├─ /projects       프로젝트 아카이브 (2차)
├─ /notice         공지·소식 (2차)
├─ /members        부원 소개 (2차, 본인 동의 필수)
└─ 404             잘못된 주소 안내
```

**만들지 않는 것**: 로그인, 관리자 페이지, 댓글, DB. 지원서는 구글폼 링크, 콘텐츠 수정은 데이터 파일 PR로 처리합니다.
